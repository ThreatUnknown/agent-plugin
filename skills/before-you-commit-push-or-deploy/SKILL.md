# Before you commit, push or deploy

Follow `threat-unknown-safety`.

1. Check the changes first with `check_my_changes`, as `check-your-changes` says. That includes
   changes you did not make, and commits that are not pushed yet.
2. Commit, push or deploy only once the check passes.
3. After you push a branch, scan it as `scan-a-repository` says.
